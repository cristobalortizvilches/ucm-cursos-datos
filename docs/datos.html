2. Repositorios Externos Oficiales

Algunas bases de datos completas (en formato SPSS .sav, Stata .dta o cartografías nacionales completas) superan los 100 MB y pueden descargarse directamente desde sus fuentes oficiales:

  • Estudio Longitudinal Social de Chile (ELSOC - COES): Repositorio oficial en Harvard Dataverse
  • Matriz de Bienestar Humano Territorial (MBHT - SUBDERE): Plataforma BHT
  • Microdatos Censo 2017 a nivel de Manzana (Geoportal de Chile): Catálogo Geoportal Censo 2017

3. Instalación de Paquetes en R

Para ejecutar todos los talleres prácticos y plantillas del curso en tu computador, abre RStudio y ejecuta el siguiente bloque en la consola:

if (!require("pacman")) install.packages("pacman")

pacman::p_load(
  tidyverse,   # Manipulación (dplyr, tidyr) y visualización (ggplot2)
  readxl,      # Lectura de archivos Excel (.xlsx)
  writexl,     # Escritura de archivos Excel (.xlsx)
  haven,       # Lectura de archivos SPSS (.sav) y Stata (.dta)
  sjlabelled,  # Etiquetado de variables y valores
  sjmisc,      # Tablas de frecuencias e inspección (frq)
  car,         # Recodificación de variables
  panelr,      # Manejo de datos longitudinales / panel
  survey,      # Diseños muestrales complejos y ponderadores
  sf,          # Datos espaciales y vectoriales
  chilemapas,  # Cartografías comunales y regionales de Chile
  leaflet,     # Mapas interactivos
  shadowtext,  # Etiquetas de texto con halo en gráficos
  ggrepel,     # Etiquetas sin superposición en ggplot2
  broom,       # Tablas ordenadas de modelos
  texreg,      # Reporte de modelos estadísticos
  usethis,     # Configuración de proyectos, Git y GitHub
  gitcreds     # Gestión de credenciales de GitHub
)
