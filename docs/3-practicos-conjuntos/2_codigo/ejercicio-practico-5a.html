2. Unión de Bases de Datos (joins)

Ahora, imaginemos que tenemos dos tablas. Una con información demográfica y otra con los resultados de una prueba médica.

# Tabla 1: Datos demográficos
demografia <- tribble(
  ~id_paciente, ~ciudad,
  "p01", "Santiago",
  "p02", "Valparaíso",
  "p03", "Talca",
  "p04", "Concepción"
)

# Tabla 2: Resultados de una prueba
resultados <- tribble(
  ~id, ~resultado_test,
  "p01", "Negativo",
  "p02", "Positivo",
  "p03", "Negativo",
  "p05", "Negativo" # Este paciente no está en la tabla demografia
)

Ejercicio 2.1: unión por la izquierda

  • Une las tablas demografia y resultados usando un left_join. La tabla de la izquierda debe ser demografia. ¿Qué pasó con el paciente p05? ¿Y con el paciente p04?
demografia_id <- demografia %>% 
  select(id = id_paciente, ciudad)

Respuesta: - El paciente p04 se mantiene, pero su resultado_test es NA porque no estaba en la tabla de resultados. - El paciente p05 desaparece porque no estaba en la tabla de la izquierda (demografia).

Ejercicio 2.2: inner_join & full_join

  • Ahora únelas con un inner_join. ¿Qué pacientes permanecen en el resultado?
inner_join(demografia_id, resultados, by = "id")

full_join(demografia_id, resultados, by = "id")

Respuesta: Solo permanecen los pacientes p01, p02 y p03, que estaban presentes en ambas tablas.

3. Reestructuración de Datos Longitudinales Volvamos a nuestro ejemplo de la encuesta ELSOC, pero ahora con datos de 3 olas y algunos NA.

elsoc_wide <- tribble(
  ~id, ~sexo, ~inseguridad_16, ~inseguridad_18, ~inseguridad_21,
  101, "Mujer", 4, 5, 5,
  102, "Hombre", 2, 2, NA,
  103, "Mujer", 5, 6, 6,
  104, "Hombre", 3, NA, 4
)

Ejercicio 3.1: Transformar a formato largo

  • Convierte elsoc_wide a un formato largo (elsoc_long)
elsoc_long <- elsoc_wide |> 
  pivot_longer(
    cols = starts_with("inseguridad_"),
    names_to = "año",
    values_to = "percepcion_inseguridad",
    names_prefix = "inseguridad_",
    names_transform = list(año = as.integer) # Convierte "16" a 2016
  ) |> 
  mutate(año = año + 2000)

Ejercicio 3.2: Análisis y visualización con datos limpios

  • Ahora, usando elsoc_long, calcula la percepción de inseguridad promedio por sexo y año, excluyendo los valores NA. Luego, crea el gráfico de líneas para visualizar la tendencia.
# 1. Calcular promedio (manejando NA)
promedios_limpios <- elsoc_long |>
  group_by(sexo, año) |>
  summarise(
    inseguridad_media = mean(percepcion_inseguridad, na.rm = TRUE)
  )

ggplot(promedios_limpios, aes(x = año, y = inseguridad_media, group = sexo, color = sexo)) +
  geom_line(linewidth = 1) +
  geom_point(size = 3) +

    subtitle = "Evolución por sexo (Datos ELSOC Ficticios)",

    y = "Promedio de Percepción de Inseguridad"
  ) +
  theme_minimal() +
  scale_x_continuous(breaks = c(2016, 2018, 2021))
