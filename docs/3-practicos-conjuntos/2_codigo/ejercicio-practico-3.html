Manipulación de Datos

Autor/a

Invalid Date

Objetivos de la sesión

El objetivo de esta sesión es aplicar de manera práctica los conceptos de manipulación de datos que vimos en la sesión teórica. Nos enfocaremos en técnicas recodificación de variables y etiquetado de datos y agrupamiento. Utilizaremos las siguientes funciones del paquete {dplyr}:

  • mutate(): Para crear o modificar variables.

  • summarise(): Para resumir datos de una o más variables.

  • group_by(): Para agrupar los datos y aplicar funciones de resumen por grupo.

  • Funciones de recodificación condicional: if_else() y case_when().

  • Recodificación de variables categóricas con car::recode().

  • Etiquetado de variables y valores con el paquete {sjlabelled}.

Trabajaremos con una base de datos ficticia, creada para esta sesión, lo que te permitirá practicar la manipulación de datos de forma reproducible.

1. Creación de la base de datos ficticia

En lugar de cargar una base de datos externa, crearemos una directamente en R. Esta base de datos simula información de encuestados con variables como id, region, sexo y edad.

# Crear una base de datos ficticia
df_base <- tibble(
  id = 1:10,
  region = c(13, 13, 5, 5, 8, 8, 7, 7, 5, 8),

2. Creando variables con mutate()

mutate() es una función clave del paquete dplyr que te permite crear nuevas variables o modificar variables existentes. Esto es fundamental para recodificar, realizar operaciones matemáticas o transformar datos.

2.1. Recodificación simple (o binaria) con if_else()

# la variable se llama sexo
# se que sexo=1->mujer & que sexo=2->hombre

df_base_sexo <- df_base |>
  mutate(sexo_cat = if_else(sexo == 1, "Hombre", "Mujer"))

2.2. Recodificación con múltiples condiciones con case_when()

Recodifica la variable ingreso en tres categorías:

  • Bajo (ingreso menor o igual 500.000) -> \((-Inf, 500000]\)
  • Medio (ingreso entre 500.001 y 1.000.000) -> \((500000, 1000000]\)
  • Alto (ingreso mayor a 1.000.000) -> \((1000000, Inf)\)
df_ingreso <- df_base %>% 
  mutate(tramo_ingreso = case_when(ingreso <= 500000 ~ "Bajo",
                                   ingreso <= 1000000 ~ "Medio",
                                   ingreso > 1000000 ~ "Alto"))

2.2b. Alternativa de recodificación múltiple para tramos con cut de R base

# Crear un nuevo dataframe llamado df_ingreso basado en df_base
df_ingreso_2 <- df_ingreso %>%
  mutate(tramo_ingreso_2 = cut(ingreso, 
                               breaks = c(-Inf, 500000, 1000000, Inf),
                               labels = c("Bajo", "Medio", "Alto"),
                               right = TRUE, # Intervalos son cerrados a la derecha (ej. (500000, 1000000])
                               include.lowest = TRUE)) # Valor más bajo sea incluido en el primer intervalo

2.3. Recodificación con car::recode()

El paquete car es popular en sociología por su función recode(), que permite una sintaxis similar a la de otros programas estadísticos como SPSS.

En el ejemplo recodificamos nivel_educativo a un formato más descriptivo usando car::recode().

  • 1 a "Básica"
  • 2 a "Media"
  • 3 a "Superior"
df_car <- df_base %>% 
  mutate(nivel_educativo_cat = car::recode(nivel_educativo,
                                           "1 = 'Básica'; 
                                            2 = 'Media'; 
                                            3 = 'Superior'"))

4. Resumiendo datos con summarise() y group_by()

summarise() colapsa múltiples valores en un solo resumen. Es útil para calcular promedios, medianas, desviaciones estándar, etc.

group_by() es una función auxiliar que, al usarse antes de summarise(), le dice a R que aplique la función de resumen a cada grupo de datos, no a toda la base.

class(df_label$region)
[1] "numeric"
df_sum <- df_label %>% 
  as_label(region) |> 
  group_by(region) %>% 
  summarise(ingreso_prom_region = mean(ingreso, na.rm = TRUE)) %>% 
  arrange(desc(ingreso_prom_region))

5. Ejercicio Integrador

Ahora combinaremos todo lo aprendido: select(), filter(), mutate(), group_by() y summarise().

df_final <- df_label %>% 
  select(id, region, sexo, ingreso) %>% 
  filter(region %in% c(13, 7)) %>% 
  mutate(
    sexo = if_else(sexo == 1, "Mujer", "Hombre")
    ) %>% 
  as_label(region) %>% 
  group_by(sexo, region) %>% 
  summarise(promedio_ingreso = mean(ingreso, na.rm = TRUE)) 
`summarise()` has grouped output by 'sexo'. You can override using the
`.groups` argument.
