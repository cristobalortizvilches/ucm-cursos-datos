Talleres Prácticos Conjuntos (DSRS & CSCC)

Guías Paso a Paso en R, Quarto y RMarkdown

Autor/a

Profesor: Cristóbal Ortiz Vilches

Los talleres prácticos integran los contenidos de Ciencia de Datos Aplicada con RStudio (DSRS) y Ciencias Sociales Computacionales (CSCC). Cada taller cuenta con una guía interactiva en formato web, una versión descargable en PDF para lectura e impresión, y el archivo de código fuente (.qmd o .Rmd) para ejecutar directamente en RStudio.

Detalle por Sesión Práctica

Práctico I: Flujo de trabajo e importación de datos

Creación de proyectos autocontenidos en RStudio (RProject), organización de directorios bajo el protocolo IPO, carga de librerías con pacman e importación de datos desde CSV, Excel, SPSS, Stata y .RData.

📖 Abrir Guía Web 📥 Descargar PDF 💻 Descargar .qmd

Práctico II: Procesamiento de datos

Creación de tibbles, selección de variables con select(), filtrado de observaciones con filter() y ordenamiento con arrange() aplicados tanto a datos simulados como a la encuesta longitudinal ELSOC.

📖 Abrir Guía Web 📥 Descargar PDF 💻 Descargar .qmd

Práctico III: Manipulación de Datos

Transformación y creación de variables con mutate(), recodificación condicional con if_else(), case_when(), cut() y car::recode(), etiquetado con sjlabelled y resúmenes agrupados con group_by() y summarise().

📖 Abrir Guía Web 📥 Descargar PDF 💻 Descargar .qmd

Práctico IV: Visualización Inicial de Datos

Introducción a la Gramática de los Gráficos con ggplot2: capas mínimas (data, aes, geom), gráficos univariados (geom_bar, geom_histogram) y bivariados (geom_point, geom_boxplot).

📖 Abrir Guía Web 📥 Descargar PDF 💻 Descargar .qmd

Práctico V (Parte 1): Procesamiento Avanzado de Datos

Identificación y tratamiento de valores perdidos (is.na(), drop_na()), unión relacional de tablas (left_join, inner_join, full_join) y transformación entre formatos ancho y largo (pivot_longer).

📖 Abrir Guía Web 📥 Descargar PDF 💻 Descargar .qmd

Práctico V (Parte 2): Introducción a Git y GitHub con RStudio

Configuración de Git, tokens de acceso personal (usethis, gitcreds), creación de repositorios versionados, registro de cambios (stage y commit) y sincronización con GitHub (push y pull).

📖 Abrir Guía Web 📥 Descargar PDF 💻 Descargar .qmd

Práctico VI: Análisis de Encuestas Complejas con survey

Preparación de datos longitudinales ELSOC (2016–2019), declaración de diseño muestral complejo estratificado y por conglomerados (svydesign), estimación de tablas ponderadas (svytable) y visualización representativa.

📖 Abrir Guía Web 📥 Descargar PDF 💻 Descargar .Rmd

Práctico VII: Visualización de datos longitudinales

Transformación de datos panel con panelr::long_panel(), construcción de gráficos de barras agrupadas, barras apiladas, comparación de baterías de ítems y series temporales de líneas con ggplot2.

📖 Abrir Guía Web 📥 Descargar PDF 💻 Descargar .Rmd

Práctico VIII: Visualización de datos espaciales

Manejo de geometrías vectoriales (sf) a nivel de manzana censal y comunal en la Región del Maule, unión de atributos territoriales de seguridad (MBHT), mapas coropléticos estáticos (ggplot2::geom_sf) y visores interactivos (leaflet).

📖 Abrir Guía Web 📥 Descargar PDF 💻 Descargar .Rmd
